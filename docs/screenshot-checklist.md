# Portfolio Evidence Notes

Use the simulation and Analytics Dashboard to capture project evidence for a portfolio or report.

Recommended project outputs:
- Main simulation response under baseline conditions
- High-noise estimator comparison
- Line-of-sight blocking behavior
- A* and Dijkstra planner comparison
- Dynamic obstacle replanning behavior
- Failure-case analysis
- Controlled experiment results table

These outputs should support the technical story: perception uncertainty, Kalman estimation, path planning, robot control limits, and quantitative evaluation.
